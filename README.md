# Modul 4 - State Hoisting, RememberSaveable, dan LaunchedEffect

**Nama:** Rajibin Putra Ilman  
**NIM:** 245150407111084

## Deskripsi

Aplikasi Pemesanan Tiket menggunakan Jetpack Compose yang menerapkan:

- State Hoisting
- RememberSaveable
- LaunchedEffect
- Validasi Input
- Perhitungan Total Harga Tiket

## Fitur

- Input nama pembeli
- Menambah dan mengurangi jumlah tiket
- Menghitung total harga tiket
- Validasi nama pembeli
- Simulasi proses pemesanan menggunakan LaunchedEffect
- Menampilkan status pemesanan
